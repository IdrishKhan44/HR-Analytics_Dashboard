
# 📊 HR Analytics Dashboard

An interactive **HR Analytics Dashboard built using Microsoft Power BI** to analyze employee workforce data, understand attrition patterns, and provide meaningful HR insights through dynamic visualizations.

## 🎯 Project Objective

The goal of this project is to transform raw employee data into an interactive dashboard that helps HR teams understand:

* Employee attrition and retention
* Department-wise workforce distribution
* Salary-wise attrition
* Age and gender distribution
* Job satisfaction
* Experience-based attrition trends
* Employee distribution across departments

## 🚀 Key Features

* 📌 Total Employees KPI
* 👥 Active Employees analysis
* 📉 Attrition Count & Attrition Rate
* 🏢 Department-wise Attrition
* 💰 Attrition by Salary Slab
* 👨‍💼 Job Role & Job Satisfaction analysis
* 🎂 Age Group Distribution
* ⚧ Gender-wise Attrition
* 📈 Attrition Trend by Experience
* 🏢 Department-wise Employee Count
* 🔎 Interactive Department and Age Group filters

## 🔍 Business Problems Solved

This dashboard helps convert large amounts of employee data into easily understandable visual insights.

It can help HR teams investigate questions such as:

* Which departments have higher employee attrition?
* How does salary level relate to attrition?
* Which age groups represent the largest workforce?
* How does employee experience relate to attrition?
* What is the distribution of employees across departments?
* How does job satisfaction vary across different roles?

## ⚙️ How to Use

1. Download or clone this repository.
2. Open `HR_Analytics_Dashboard.pbix` using **Microsoft Power BI Desktop**.
3. If required, update the Excel data source path.
4. Refresh the dataset.
5. Use the interactive filters and visuals to explore the HR insights.
